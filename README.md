## Features

- 🌙 **Dark / Light / System** appearance mode
- 🎨 **Live colour theme switching** (Ocean Blue, Green, Dark Blue)
- 🌍 **English & Arabic** with instant language switching (no restart)
- 🖼 **Illustrator-quality export** — full artboard, 300 DPI default, 4× anti-aliasing
- 🐛 **Crop bug fixed** — EPS uses `%%BoundingBox`; AI uses full MediaBox
- 💾 **Preferences saved** between sessions
- 📦 **Standalone installer** — ships Ghostscript, no Python needed on target machine

## Quick start (developers)

```powershell
# 1. Clone
git clone https://github.com/SherifOthman/Studio-Tools.git
cd Studio-Tools

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run
python main.py
```

Ghostscript must also be installed: download from
<https://github.com/ArtifexSoftware/ghostpdl-downloads/releases>
or run `build\build.ps1` which handles it.

---

## Build a distributable installer

```powershell
.\build\build.ps1
# Produces:  dist\StudioTools.exe       (standalone app, ~15 MB)
#            dist\StudioTools-Setup.exe  (full installer with Ghostscript)
```

Requirements: Python 3.11, PyInstaller, Pillow, Inno Setup 6 — all installed automatically by the script.

## Project structure

```

├── main.py              ← entry point
├── requirements.txt

│   │   └── coming_soon.py

└── build/
    ├── build.ps1        ← one-click build script
    ├── gen_icon.py      ← icon generator

```
